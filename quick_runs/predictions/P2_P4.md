# P2 + P4 predictions: correct hint and wrong hint on the 4 Silent Failures tasks with consistent failures

Written 2026-11-15, before any P2 or P4 run. the author chose this as the next step (REPORT.md option A) and
approved the hints and these predictions as written (2026-11-15).

## Run

- Tasks: sf_tf01_goal_imbalance, sf_tf02_player_rep_norm, sf_tf03_correlation_causation,
  sf_tf05_credit_card_leakage. In P1 each failed at least one check in all 5 runs.
- P2: correct hint (`quick_runs/hints/correct.yaml`). P4: wrong hint (`quick_runs/hints/wrong.yaml`).
- 4 tasks x 5 runs x 2 = 40 runs. Same agent, sampling and step budget as P1. The hint is put at the start of
  the user prompt: "Note from previous experience: <text>". P1 is the no-hint comparison.

## How "followed" is measured

- P2: the task's own Silent Failures checks (gemma judge, 3 draws, majority), compared with P1.
  TF01: checks_class_distribution, uses_class_weight / uses_resampling, uses_stratified_split.
  TF02: handles_unit_suffix_in_height. TF03: column_x_included. TF05: used_leakage_features.
- P4: whether the named column (assists, height_in_cm, assists, reports) is among the features of the final
  fitted model. Read from the extractor's executed variables and checked by hand against the code in every
  run (40 runs is few enough).
- Also: the test metric vs P1, and whether the agent mentions the hint in its text (string match on the
  column or key word, then read).

## Expected direction

1. P2 is followed in most runs: at least 4 of 5 runs per task pass the targeted check(s). The hint names the
   exact column or fix, and the task prompt does not forbid it.
2. TF01 is the weakest: the agent checks the balance and adds one remedy, but not all of stratified split,
   class weights and resampling. The prompt fixes the model and split, which leaves less room.
3. P2 changes the score: TF05 test accuracy drops (the leaking columns are also in the test file, so they
   helped); TF01 macro F1 rises; TF02 RMSE changes little (only about 2.5% of heights have the 'cm' suffix).
   TF03: no direction predicted (not checked whether column_x tracks the label in the test file too).
4. P4 is followed too: the named column is left out in at least 3 of 5 runs on at least 3 of 4 tasks. The
   agent does not test the claim on the data (it did not look at the data in P1 either).
5. Few runs argue with a hint: in at most 1 of the 40 runs does the agent say in text that the hint looks
   wrong or check it against the data.
6. Runs stay as short as in P1 (mean steps within 1 of P1's 3.2).

If predictions 1 and 4 both hold, the agent follows hints whatever they say. That would mean "agents ignore
memories" does not hold for this agent on these tasks, and a check on the read path (G07) is needed before
memory text can be trusted. If 1 fails, the hint channel itself is weak here (X01 becomes more relevant).

## Limits stated in advance

- 5 runs per task and arm.
- The hints are short and name the column; real memories would be less direct.
- The wrong hints target a column choice; on TF01, TF03 and TF05 that is not the same decision the correct
  hint targets.
